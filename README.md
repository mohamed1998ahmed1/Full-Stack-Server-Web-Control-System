# 🚀 Full-Stack Server & Web Control System
### منظومة الويب المتكاملة للتحكم وإدارة السيرفر

منظومة متكاملة لإدارة وتحكم المواقع والسيرفرات عن بعد، تدمج بين واجهة أداة حديثة وسريعة الاستجابة، وخلفية معالجة قوية وآمنة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** React (TypeScript) / Vite
* **Backend:** .NET Core Web API (C#)
* **IDE & Environment:** Visual Studio 2022

---

## ✨ المميزات الرئيسية (Key Features)

* **لوحة تحكم مركزية:** تفاعل مباشر ومستقر بين العميل (Client) والخادم (Server).
* **إدارة السيرفر:** معالجة البيانات والطلبات بكفاءة عالية وبنية معمارية نظيفة.
* **واجهة مستخدم متجاوبة:** تجربة متكاملة مصممة بأحدث أدوات التطوير.

---

## ⚙️ طريقة التشغيل محلياً (Setup)

1. **الخادم (Backend):**
   افتح ملف `ReactApp1.sln` عبر Visual Studio وشغّل مشروع `ReactApp1.Server`.

2. **الواجهة (Frontend):**
   انتقل إلى مجلد `reactapp1.client` ثم نفّذ الأوامر:
   ```bash
   npm install
   npm run dev
